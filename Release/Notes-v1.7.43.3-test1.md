# Item Intelligence 1.7.43.3-test1

- Added Japanese, Korean and Turkish. All 11 official Quasimorph languages now have a complete interface, including equipment and clone upgrades.
- Revised existing translations for clearer, shorter wording. Corrected outdated skill and damage names using Quasimorph 1.0.4.590s.
- Clarified research material totals, recipes, body parts and acquisition sources.
- Updated the hotkey hint: opening the catalog does not require hovering an item.
- Added Japanese and Korean fonts to the mod's settings menu, improved Japanese punctuation wrapping, and kept Korean words together when wrapping notes.
- Replaced unsupported text symbols with readable punctuation. All translated text now fits the character sets of the game's bundled fonts; visual icons are unchanged.

Choose **Auto (Game)** or a specific language under **MCM → Item Intelligence → Language**. The browser changes language after saving settings. Restart to refresh the settings captions. Item and faction names follow the game's language.

For a quick check, open the catalog immediately after loading, inspect a weapon and a material used in upgrades, then read a long Loot note. Try the normal and large windows. Changing only the mod language should keep game item names readable.

This is a local test build. Probability calculations, recipes, upgrade costs and saves are unchanged.
