# Item Intelligence 1.7.43.2

Resources can still be useful after ship research is complete. Magnum now shows their uses in weapon and armor upgrades, clone genomes and class modifications, with links to the exact equipment upgraded using each resource. Overview links directly to this information. Pact ritual components, implants and augmentations also show their uses.

- Covers 61 project-upgrade materials and 350 individual equipment upgrade configurations in Quasimorph 1.0.4.590s.969afc6.
- Follows each item's actual upgrade material list, including overrides of the standard list. Upgrade uses stay visible after research is complete, while remaining ship-research totals retain their existing meaning.
- Corrects grenade-launcher ammunition links, including Shaker, using the game's exact reload restrictions.
- Fixes default weapon-mode damage types and displays each mode's traits and status effects, including differences between Reaper's attacks.
- Adds links between augmentation items and the weapons they provide when installed.
- Opens the catalog on the first browser hotkey press when no item has been inspected yet, in space or after resuming a mission. Custom key bindings are supported.
- Includes the new labels in all eight interface languages.

The user verified the preceding test5 build in game. Stable promotion changes release identity and packaging without changing gameplay or interface behavior. All build contracts and automated suites pass; the installed game's record types and parser were used to verify 1,786 upgrade-use links.

## По-русски

Во вкладке «Магнум» теперь видно, какие ресурсы нужны для улучшения оружия, брони, геномов и классов. Есть ссылки на конкретное снаряжение, а в «Обзоре» — переход к этим сведениям. Пометки сохраняются после завершения исследований корабля. Также отмечены компоненты ритуалов пактов, импланты и аугментации для клонов.

Исправлены боеприпасы гранатомётов, типы урона и свойства отдельных режимов атаки. Добавлены связи между устанавливаемыми конечностями и их оружием. Справочник открывается первым нажатием назначенной клавиши, даже если до этого не наводить курсор на предмет.
