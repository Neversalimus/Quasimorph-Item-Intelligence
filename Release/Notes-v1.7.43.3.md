# Item Intelligence 1.7.43.3

- Added **On ship** at the top of every item’s Overview, so you can check your stock when choosing mission loot. Counts update while the page is open.
- Counts all cargo tabs, the fridge and items waiting in the recycler. Clone inventories and items already being recycled are excluded; upgraded variants have separate counts. Empty stock shows **0**, unavailable data shows **?**.
- Added Japanese, Korean and Turkish, bringing the interface to all 11 official game languages. Revised the existing translations for clearer wording and current game terminology.
- Improved Japanese and Korean text wrapping, Turkish capitalization and long tab labels. Fixed font recovery when the game loads a language’s fonts late.
- Reduced repeated translation and reflection lookups and unnecessary UI updates. Improved cleanup when switching saves and languages.
- Hardened package preparation and expanded automated checks for localization, UI reuse and ship stock.
