Item Intelligence 1.7.42.8 adds optional verbose logging and substantially reduces normal Player.log noise.

- Added MCM / config.ini option `Verbose logging`, disabled by default.
- Normal mode keeps only concise lifecycle/status messages plus warnings and errors.
- Detailed runtime, UI, index, navigation, performance and audit diagnostics remain available when verbose logging is enabled.
- The setting is localized in all eight interface languages and persists across restarts.

Tested on Quasimorph 1.0.4.582s.c4335c5.
