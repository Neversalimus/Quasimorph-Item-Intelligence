# Item Intelligence 1.7.43.4

- Added spoilage results to **Overview** and **Recipes**, with clickable links to the resulting items.
- Added the reverse relation: resources now list the items that can spoil into them. This covers food and perishable quasimorph equipment.
- Added shelf lives for fresh items and a note that refrigeration pauses spoilage. Each step of a spoilage chain is shown separately.
- Translated the new labels into all 11 supported languages.
- Reduced repeated catalog sorting and unnecessary work when opening the browser.
- Improved browser history, tab-scroll and ship-stock state handling, and expanded automated regression checks.
