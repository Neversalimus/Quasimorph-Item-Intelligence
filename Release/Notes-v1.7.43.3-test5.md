# Item Intelligence 1.7.43.3-test5

- Added an **On ship** count at the top of every item's Overview, including loot with no ship research requirements.
- Counts stack quantities across cargo tabs, the fridge and the idle recycling storage. Items being recycled and clone inventories are excluded. Upgraded item variants are counted separately.
- Reads the current save in both space and missions. The displayed count refreshes while Overview is open; unchanged counts do not redraw the page. Missing cargo data displays **?**, while an empty stock displays **0**.
- Translated the new label into all 11 supported languages.

Includes the language, maintenance and UI fixes from earlier builds in this test series. This remains a test release.
