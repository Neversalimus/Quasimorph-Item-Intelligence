# Item Intelligence 1.7.43.5

- Fixed chip recipe links for every piece of an armor set, including helmets, leggings and boots.
- Added links for default ammunition unlocked together with weapons. Chip chances retain the original pool weights and account for shared unlocks.
- Added **Weapon type** to the Weapons catalog. Categories follow the game's classifications, so weapons can be found even when their IDs use a different name.
- Search now finds weapons by their localized class and built-in perks. Combine filters such as `weapon:AssaultRifle perk:suppressor`, or use class and perk names in the game language.
- Updated search hints and chip explanations in all 11 supported languages.
