# Item Intelligence 1.7.42.5 — стабильная версия

Большое окно и масштаб, немецкий/польский/китайский интерфейс, исправленные источники имплантов и китайские подписи MCM. Рабочий код принятого Test5 сохранён; изменены номер версии и маркер запуска. Приёмка и границы проверки: `Support/ReleaseAcceptance17425.md`.

## Установка из исходников

Закрой Quasimorph. В папке `ItemIntelligence` запусти через PowerShell 7:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

При необходимости укажи игру:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -GameRoot "C:\Program Files (x86)\Steam\steamapps\common\Quasimorph"
```

Установщик запускает проверки, собирает DLL против установленной игры и готовит `C:\QM_Workshop\ItemIntelligence`. Он не публикует обновление автоматически и не перезаписывает подписанную копию Steam.

## Публикация автором

Используй полный архив `Quasimorph_ItemIntelligence_v1.7.42.5_Release_Publish_Full.zip` и команды из его `START_HERE_RU.md`.

1. `Prepare_QII_v1.7.42.5_Release.ps1` восстанавливает точный коммит из проверенного Git bundle, сверяет сборку игры и готовит неизменяемый комплект в `C:\QM_Workshop\Frozen\ItemIntelligence-v1.7.42.5`. Исправление GitHub 404 уже включено.
2. Команда в консоли Quasimorph публикует именно подготовленный комплект в существующий публичный предмет:

```text
mod_updateworkshopitem 3780078201 C:\QM_Workshop\Frozen\ItemIntelligence-v1.7.42.5\payload FALSE
```

3. После успешного обновления включи PUBLIC, отключи DEV и перезапусти игру. Проверь F2 и маркер:

```text
[ItemIntelligence] ACTIVE VERSION 1.7.42.5 (StableRelease17425).
```

4. Запусти `Publish_QII_v1.7.42.5_GitHub.ps1 -WorkshopPublished`. Скрипт проверит тот же комплект, опубликует коммит и тег атомарно, загрузит архив, скачает его для сравнения SHA256 и откроет релиз. При обрыве повтори ту же команду: исходники, файлы и квитанция сохраняются для продолжения.

Не пересобирай и не заменяй файлы между Workshop и GitHub. При конфликте с существующими исходниками или каталогом подготовки скрипт остановится и сохранит их. Полный предыдущий DEV-маршрут повторять для публикации не требуется.

Ниже оставлен дополнительный маршрут для последующих проверок и диагностики.

## Полный маршрут проверки большого окна и масштаба

1. Открой F2. Внизу находятся **«Большое окно»** и **«Масштаб − / +»**. Нажми «Большое окно»: панель займёт 94% ширины и высоты экрана, начальный масштаб — 150%. Для возврата нажми «Обычное окно».
2. На 1920×1080 сравни 150% и 175%. Проверь также 200%: строк станет меньше, но кнопки, поиск и нижняя панель должны оставаться доступными. Уменьшение числа строк — ожидаемое поведение. Колесо, полоса прокрутки и PageUp/PageDown должны доводить до последней записи.
3. Открой Loot с шестью колонками и пояснениями, Trade в обоих видах, Factions и Recipes. Раскрой каталог, прокрути до конца, проверь поиск. Наведи на режим оружия в Overview: подсказка должна оставаться на экране. Повтори с выключенными значками в MCM.
4. Поставь разный масштаб в обычном и большом окне, закрой F2 и перезапусти игру. Каждый режим должен помнить свой масштаб и последний выбранный вид. Сохрани несвязанную настройку MCM: размер окна не должен сброситься.
5. Если используешь Modder Mode, проверь доступность боковой панели; она входит в выделенную ширину и не должна уходить за край. Нажимать кнопку создания предмета для проверки размеров не нужно.
6. По возможности проверь 1366×768 и смену разрешения. При нехватке места масштаб автоматически ограничивается; рядом с кнопками отображается фактический процент. Сделай полные скриншоты экрана: обычный вид 100%, большой 150% и 200%, особенно Loot и каталог.

Пришли Player.log и эти скриншоты; укажи разрешение и выбранный язык. В логе есть `[ItemIntelligence][BrowserViewport]` с разрешением, масштабом и числом строк. Если нужна точная ручная настройка при закрытой игре, config.ini содержит `BrowserExpanded`, `BrowserWindowZoom` и `BrowserExpandedZoom`. Через MCM менять их не требуется.

## Проверка источников имплантов

1. В космосе открой F2 → имплант → Loot и дождись завершения подготовки источников. Раскрой источники у врагов.
2. Посмотри несколько обычных и квазиморфских имплантов. Числовой процент теперь относится к успешной установке. «Условно» означает возможный источник без подтверждённого процента: это ожидаемая пометка для зависимых от случайных аугментаций случаев. «Ампут. X%» по-прежнему показывает отдельный шанс извлечения.
3. Сделай скриншоты таблиц: один с числом и один с «Условно», если такие строки есть. Проверь, что нет NaN, пустых подписей и обрезанного текста.
4. Оставь выбранным интересующий имплант и нажми **Ctrl+Shift+F10**. В обычный `diagnostics_report.txt` будет добавлен раздел `[EnemyImplantEvidence]` с игровыми записями и результатом расчёта. Modder Mode для этой клавиши не нужен. Полный путь появляется в Player.log в строке `Diagnostics exported:`. При повторном экспорте файл перезаписывается: для нескольких предметов сохрани копии.
5. Открой Loot на миссии, затем вернись к тому же предмету: не должно быть исключений или зависания интерфейса. Пришли Player.log, diagnostics_report.txt и скриншоты. В логе ожидается строка `[ItemIntelligence][EnemyBodySources]` после завершения индекса.

Для этой проверки не нужно добывать редкий имплант или специально создавать врагов. Исходный рассказ об импланте Ксио остаётся неподтверждённым до проверки точной игровой записи.

## Проверка языков

1. Оставь язык игры русским. В MCM → Item Intelligence выбери `Deutsch`, сохрани и открой F2. Проверь заголовки, поиск и каталог; названия игровых предметов должны оставаться русскими.
2. Посмотри Overview и подсказку режимов оружия, Trade в обоих видах, Loot с раскрытыми пояснениями и Factions. Проверь десятичные запятые, время, проценты, переносы и обрезанные подписи.
3. Повтори с `Polski` и `简体中文 / Chinese`. Для китайского особенно нужны скриншоты Overview и раскрытой Loot: иероглифы должны отображаться вместе с русскими названиями предметов без квадратов.
4. Верни `English`, затем `Русский`: интерфейс и шрифт должны возвращаться корректно. Смена языка QII не меняет язык самой игры и поиск по игровым названиям.
5. Выбери один из новых языков, сохрани, перезапусти игру и проверь, что выбор сохранился. Подписи самого меню MCM обновятся после этого перезапуска; браузер F2 меняется сразу после сохранения.
6. Выбери `Auto (Game)`. По возможности последовательно поставь игре немецкий, польский и упрощённый китайский и открой F2: язык мода должен следовать игре. После смены игрового языка подожди несколько секунд, затем переоткрой F2. Верни привычный язык игры.

Для разбора пришли Player.log от этого запуска и несколько скриншотов новых языков. Укажи, если тест проходил на разрешении ниже 1920×1080. Если заметишь проблему, приложи экран целиком и назови язык мода и игры.

Без MCM можно изменить `UiLanguage=Auto (Game)` в config.ini загруженной DEV-копии при закрытой игре. Допустимы также `English`, `Русский`, `Deutsch`, `Polski`, `ChineseSimp` или `简体中文 / Chinese`. Предпочтительный тест — через MCM.

Архив содержит исходники и установщик. Готовая DLL создаётся на твоём Windows; DLL игры в архив не включены.
