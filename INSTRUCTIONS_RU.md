# Item Intelligence 1.7.42.5-test2 — импланты и языки

База: выпущенная 1.7.42.4 и предыдущий DEV-тест локализации. Этот полный архив заменяет Test1: в нём уже есть немецкий, польский, упрощённый китайский и выбор языка через MCM.

## Сборка и загрузка DEV

Закрой Quasimorph. В извлечённой папке `ItemIntelligence` запусти `Install.ps1` через PowerShell 7:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

При необходимости укажи игру явно:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -GameRoot "C:\Program Files (x86)\Steam\steamapps\common\Quasimorph"
```

Установщик проверяет исходники и переводы, запускает тесты, собирает DLL и готовит `C:\QM_Workshop\ItemIntelligence_DEV`. Затем выполни в консоли разработчика Quasimorph:

```text
mod_updateworkshopitem 3781927679 C:\QM_Workshop\ItemIntelligence_DEV FALSE
```

После обновления включи существующий DEV-предмет и отключи публичную копию на время теста, затем перезапусти игру. В логе должен появиться именно этот маркер:

```text
[ItemIntelligence] ACTIVE VERSION 1.7.42.5-test2 (ImplantBodyLanguagesTest02).
```

## Проверка источников имплантов

1. В космосе открой F2 → имплант → Loot и дождись завершения подготовки источников. Раскрой источники у врагов.
2. Посмотри несколько обычных и квазиморфских имплантов. Числовой процент теперь относится к успешной установке. «Условно» означает возможный источник без подтверждённого процента: это ожидаемая пометка для зависимых от случайных аугментаций случаев. «Ампут. X%» по-прежнему показывает отдельный шанс извлечения.
3. Сделай скриншоты таблиц: один с числом и один с «Условно», если такие строки есть. Проверь, что нет NaN, пустых подписей и обрезанного текста.
4. Оставь выбранным интересующий имплант и нажми **Ctrl+Shift+F10**. В обычный `diagnostics_report.txt` будет добавлен раздел `[EnemyImplantEvidence]` с игровыми записями и результатом расчёта. Modder Mode для этой клавиши не нужен. Полный путь появляется в Player.log в строке `Diagnostics exported:`. При повторном экспорте файл перезаписывается: для нескольких предметов сохрани копии.
5. Открой Loot на миссии, затем вернись к тому же предмету: не должно быть исключений или зависания интерфейса. Пришли Player.log, diagnostics_report.txt и скриншоты. В логе ожидается строка `[ItemIntelligence][EnemyBodySources]` после завершения индекса.

Для этой проверки не нужно добывать редкий имплант или специально создавать врагов. Исходный рассказ об импланте Ксио остаётся неподтверждённым до проверки точной игровой записи.

## Проверка языков

1. Оставь язык игры русским. В MCM → Item Intelligence выбери `Deutsch`, сохрани и открой F2. Проверь заголовки, поиск и каталог; названия игровых предметов должны оставаться русскими.
2. Посмотри Overview и подсказку режимов оружия, Trade в обоих видах, Loot с раскрытыми пояснениями и Factions. Проверь десятичные запятые, время, проценты, переносы и обрезанные подписи.
3. Повтори с `Polski` и `简体中文 / Chinese`. Для китайского особенно нужны скриншоты Overview и раскрытой Loot: иероглифы должны отображаться вместе с русскими названиями предметов без квадратов.
4. Верни `English`, затем `Русский`: интерфейс и шрифт должны возвращаться корректно. Смена языка QII не меняет язык самой игры и поиск по игровым названиям.
5. Выбери один из новых языков, сохрани, перезапусти игру и проверь, что выбор сохранился. Подписи самого меню MCM обновятся после этого перезапуска; браузер F2 меняется сразу после сохранения.
6. Выбери `Auto (Game)`. По возможности последовательно поставь игре немецкий, польский и упрощённый китайский и открой F2: язык мода должен следовать игре. После смены игрового языка подожди несколько секунд, затем переоткрой F2. Верни привычный язык игры.

Для разбора пришли Player.log от этого запуска и несколько скриншотов новых языков. Укажи, если тест проходил на разрешении ниже 1920×1080. Если заметишь проблему, приложи экран целиком и назови язык мода и игры.

Без MCM можно изменить `UiLanguage=Auto (Game)` в config.ini загруженной DEV-копии при закрытой игре. Допустимы также `English`, `Русский`, `Deutsch`, `Polski`, `ChineseSimp` или `简体中文 / Chinese`. Предпочтительный тест — через MCM.

Архив содержит исходники и установщик. Готовая DLL создаётся на твоём Windows; DLL игры в архив не включены.
